# My Maharani — Part 1 v2

A richer visual version of Part 1 with an elegant Maharani / romantic / cinematic direction.

## Included

- Warm ivory, blush, burgundy and champagne palette
- Decorative patterns and ornamental details
- Royal visual accents
- Manual 8-name story navigation
- Individual image slot for every name
- Emoji + meaning for every name
- Cinematic photo frame and transition
- Personal secret-message section
- Birthday countdown to 06 June 2027 (IST)
- Responsive phone, tablet and desktop layout
- No external libraries or network dependencies

## Replace the placeholders

The `images/` folder contains eight working placeholder SVG files:

- `devi.svg`
- `maharani.svg`
- `madam-ji.svg`
- `putuli.svg`
- `ice-cream.svg`
- `lady-don.svg`
- `bilei.svg`
- `miss.svg`

Replace each file with her real photo. If you use JPG/PNG instead, update the matching `image` value in `script.js`.

## Run

Open `index.html` in a modern browser.

## Final deployment

When the complete website is finished, upload the project to a static web host. Only after the final public URL exists should the QR code be generated.

Parts 2–4 are intentionally not included yet.
